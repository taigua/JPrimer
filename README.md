# J Primer中文版

这是[J Primer](https://code.jsoftware.com/wiki/Help/Primer/Title)的中文翻译。
[J](https://jsoftware.com/)是一门[阵列编程](https://en.wikipedia.org/wiki/Array_programming)（Array Programming）语言，
由[Kenneth E. Iverson](https://en.wikipedia.org/wiki/Kenneth_E._Iverson)和[Roger Hui](https://en.wikipedia.org/wiki/Roger_Hui)
于上世纪90年代发明。J语言是[APL](https://en.wikipedia.org/wiki/APL_(programming_language))语言（也是Iverson发明）的一种方言，
延续了APL鲜明的简洁性，它在数学和统计学程序设计上十分高效，特别是在需要进行矩阵运算的场合。

本书由[mdBook](https://github.com/rust-lang/mdBook)制作。PDF版本由[mdbook-pandoc](https://github.com/max-heller/mdbook-pandoc)
调用[Pandoc](https://pandoc.org/)进行转换，并使用[LaTeX](https://www.latex-project.org/)生成。
