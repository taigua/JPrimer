# 组件文件

组件文件`jfile`可以看作是存储在文件中的盒装列表。文件中盒装列表的项被称为组件。
脚本`jfiles.ijs`提供了处理`jfile`的实用程序。

```j
   load 'jfiles'
   f =. 'user\data.jf'
   jcreate f
1
   'first component' jappend f
0
   (1.5+i.2 3) jappend f
1
   ('asdf';23) jappend f
2 3
   (<'mum';'dad') jappend f
4
```

`jsize`的结果给出文件信息，包括第一项和最后一项的索引。

```j
   jsize f
0 5 1408 0
   jread f;0
+---------------+
|first component|
+---------------+
   jread f;1
+-----------+
|1.5 2.5 3.5|
|4.5 5.5 6.5|
+-----------+
   jread f;2
+----+
|asdf|
+----+
   jread f;3
+--+
|23|
+--+
   jread f;4
+---------+
|+---+---+|
||mum|dad||
|+---+---+|
+---------+
   'new' jreplace f;3
3
   jread f;i.5
+---------------+-----------+----+---+---------+
|first component|1.5 2.5 3.5|asdf|new|+---+---+|
|               |4.5 5.5 6.5|    |   ||mum|dad||
|               |           |    |   |+---+---+|
+---------------+-----------+----+---+---------+
```
