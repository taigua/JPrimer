# 列表相加的J方式

J知道如何处理单个数字，但它也知道如何处理列表。

因为J知道如何进行列表相加，所以可以编写第三个更简单的版本。
```j
addb =: 4 : 'x + y'
```

将此定义添加到临时脚本文件中，运行脚本并对其进行测试。
```j
   2 3 4 addb 4 5 6
6 8 10
```

现在，你可能意识到`addb`是如此简单，以至于没有必要定义它。
```j
   2 3 4 + 4 5 6
6 8 10
```

在J中，你可以直接把两个数字列表相加，因为动词`+`知道所有关于数字列表的信息。

多年来的研究和思考已经渗入J动词与列表一起工作的方式。例如，如果你想对列表中的每个数字加1。
```j
   1 adda 2 3 4
3
```

基本方式的动词`adda`给出了答案，但这是错误的答案。事情是这样的。`while.`使用左参数的长度（为1）来确定在结果中应有多少个元素，
因此只计算第一个结果。
```j
   2 3 4 adda 1
|index error
|   r=.r,(i{x.)+(i    {y.)
```

上面的代码会产生一个错误，因为`while.`使用长度3（左参数中的数字个数）但是右参数没有那么多数字，所以你会得到一个错误。

但是J动词`+`以你喜欢和期望的方式处理这两种情况！
```j
   1 + 2 3 4
3 4 5
   2 3 4 + 1
3 4 5
```

谢天谢地，动词`addlist`和`adda`都在一个临时文件中，很容易删除，因为在J中显然不需要它们。现在关闭并删除那个临时脚本。

操纵列表而不是单个元素，这个简单概念在整个J中得到了扩展。
```j
   2 4 6 * 7 8 9
14 32 54
   2 * 2 3 4
4 6 8
   2 3 4 * 2
4 6 8
   5 6 7 % 2
2.5 3 3.5
   2 3 4 - 3
_1 0 1
```

它也适用于比较原语。
```j
   2 3 4 = 7 3 8
0 1 0
   2 < 0 1 2 3 4 5
0 0 0 1 1 1
   't' = 'testing'
1 0 0 1 0 0 0
```

如果它适用于原语，那么像摄氏度这样的动词呢？
```j
   fahrenheit _40 0 100
_40 32 212
```

适用于二元转换吗？
```j
   'c' convert _40 32 212
_40 0 100
   'f' convert _40 0 32 100 212
_40 32 89.6 212 413.6
```

动词的拓展使其能够一致地操作列表，这非常非常强大，也是J与大多数其他语言的显著区别。
重要的是，你要把这一点融入到思考解决问题的方式中。
