# 第四个检查点

到了这个检查点，你应该明白：

- 原语适用于列表
- 你的自定义动词适用于列表
- 如何使用几个新动词
- 如何使用绘图功能
- 比较原语，如`=`，给出数值0和1作为结果

通过做以下练习来检查你的理解：

- 查找[NuVoc](https://code.jsoftware.com/wiki/NuVoc)中动词`i. (integers)`、`$ (shape)、`? (roll)`，
  `^ (power)`和`o. (circle)`的定义；本指南在大多数情况下，只介绍了它们的一部分功能，因此你必须仔细阅读定义，
  以便能够忽略尚未介绍的部分，并挑选出已经介绍的部分
- 用这些新的原语进行实验
