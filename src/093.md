# 挂钩

`train`是由两个或三个单词组成的一个序列，具有特殊的含义。由两个动词组成的序列是一个挂钩，其计算方法如下：

```j
  (f g) y	evaluates as	y f g y
x (f g) y	evaluates as	x f g y
```

假设你想缩放一个数字列表，使结果是每个数字除以列表中的最大值。列表上的最大值由将副词`/`应用于动词`>.`得到的派生的动词给出。

```j
   a =. 3 5 8 2 7
   maxover =. >./
   maxover a
8
```

要把参数除以参数的最大值，你可以使用：

```j
   a % maxover a
0.375 0.625 1 0.25 0.875
```

上面的代码可以写成一个挂钩。

```j
   (% maxover) a
0.375 0.625 1 0.25 0.875
```

现在可以将缩放定义为`% >. /`组成的挂钩。

```j
   scale =. % >./
   scale a
0.375 0.625 1 0.25 0.875
```
