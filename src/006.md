# 开始

本章假设你在[JQt IDE](https://code.jsoftware.com/wiki/Guides/Qt_IDE)（交互式开发环境）中使用[最新版本的J](https://code.jsoftware.com/wiki/System/Installation)。

Term窗口是一个执行窗口。你在Term窗口中键入J语句，当按Enter键时，J将执行它们并显示结果。

在Term窗口中键入以下行并按Enter键。
```j
   2 + 3
```

语句被执行并显示结果。输入以下行并按Enter键。
```j
   5 - 3
```

你的会话应该看起来像这样：
```j
   2 + 3
5
   5 - 3
2
```

你输入的行缩进三个空格，J的答案从行首开始。
