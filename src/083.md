# 链接 - 双子 ;

双子`; (link)`可以很容易地创建一个盒装名词列表。

```j
   2 3 4 ; 4 7 9
+-----+-----+
|2 3 4|4 7 9|
+-----+-----+
   'abc' ; 5 7 9
+---+-----+
|abc|5 7 9|
+---+-----+
   (2 3 $ 'abcdef') ; (i. 3 4) ; 23
+---+---------+--+
|abc|0 1  2  3|23|
|def|4 5  6  7|  |
|   |8 9 10 11|  |
+---+---------+--+
```

在[NuVoc](https://code.jsoftware.com/wiki/NuVoc)中查找[链接](https://code.jsoftware.com/wiki/Vocabulary/semi#dyadic)。
注意它的二元秩是`_ _`，所以它适用于整个左参数和整个右参数。它总是把左参数装盒，而右参数如果已经是*盒装*，则不会被装盒。
只有当右参数不是*盒装*时，才会对它进行装盒，从而使以下操作运行：

```j
   'abc' ; 'defg' ; 'hijkl'
+---+----+-----+
|abc|defg|hijkl|
+---+----+-----+
```

从右到左计算为：

```j
   'abc' ; ('defg' ; 'hijkl')
```

所以最左边`;`的右参数已经是*盒装*了，就不会再被装盒了。再次装盒的话，会是什么样子？

```j
   'abc' ; < 'defg' ; 'hijkl'
+---+------------+
|abc|+----+-----+|
|   ||defg|hijkl||
|   |+----+-----+|
+---+------------+
```

盒子可以嵌套！
