# 第三个检查点

到了这个检查点，你应该明白：

- 动词调试的一般方法
- 控制词如何将将句子分组成块来创建控制结构
- T块测试结果是什么
- 测试结果如何决定执行哪个B块
- 测试结果如何决定控制结构的执行何时结束

通过做以下练习来检查你的理解：

- 单步调试温度转换动词
- 创建一个临时脚本文件，并定义一个名为`conv`的动词，它类似于温度转换，但坚持使用`'f'`参数来进行华氏度的转换，并且当
  做参数既不是`'f'`也不是`'c'`时，返回一个字符串表示错误。
  **提示**：使用下面的控制结构示例，或者使用`select.`控制结构
  ```j
  if. x = 'c' do. ...
    elseif. x = 'f' do. ...
    elseif. 1 do. 'left arg not c or f'
  end.
  ```
- 创建一个临时脚本文件，并定义一个名为`plus`的双子，将其左参数和右参数相加。但是，如果有错误，它应该给出一个字符串结果。
  **提示**：
  - 使用`dyad : 0`；
  - `4 plus 9`应当返回13；
  - `'a' plus 9`应当返回错误字符串（比如，`'there was an error'`）;
  - 使用`try.`控制结构来捕捉错误并给出字符串结果。
