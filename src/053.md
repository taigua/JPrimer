# 绘图

要使用绘图功能，你需要加载它。
```j
   load 'plot'
```

尝试一个简单的绘图。
```j
   plot 5 10 23 45 8
```

![](../pics/Help-plot.gif)

绘图位于一个单独的窗口。关闭绘图窗口，丢弃它。

现在可以绘制数据了，让我们看一下在前一节中使用的一些原语。
```j
   plot 2 ^ i. 5
   plot ? 5 $ 100
   plot ? 50 $ 100
   plot ? 100 $ 100
   plot ? 1 + i. 50
   plot ? 1 + i. 100
```

通过左参数定制绘图。
```j
   'TITLE myplot;TYPE bar' plot 2 ^ i. 5
```

或者试试之前计算的正弦值。
```j
   plot 1 o. i. 16  
```

在`trig.ijs`脚本中定义了一系列实用程序，你可以在这里使用。使用load来加载该脚本。
```j
   load 'trig'
   plot sin i. 16
```

为了生成更精细的图，你需要在类似的范围内提供更多的数值结果。
```j
   plot sin 0.2 * i.60
   plot cos 0.2 * i.60
```
