# 外部 !:

J与环境交互是由连词`!: (foreign)`完成的。在大多数情况下，外部结果是提供特定服务的动词。
`foreign`的左参数选择一个通用的服务族，右参数选择一个特定的服务。由左参数选择的服务族是：

```j
  0  scripts
  1  files
  2  host commands
  3  types
  4  names
  5  representations
  6  time
  7  space
  9  global parameters
 11  windows
 13  debug
 15  dynamic link library (shared library)
 18  locales
128  numerical functions
```

[NuVoc](https://code.jsoftware.com/wiki/Vocabulary/bangco)中记录了外部连词的概述，
[J词典的词汇表](https://code.jsoftware.com/wiki/Vocabulary/Foreigns)中有更详细的文档。

在前面的章节中，你已经遇到了一些外部连词的具体用法。

派生动词`9!:11`用于打印精度控制。`9`选择全局参数族，`11`给出一个派生动词，用于设置打印精度。

加载动词使用`0!:0`加载脚本。左参数选择脚本族。查看[定义](https://code.jsoftware.com/wiki/Vocabulary/Foreigns#m0)。
右参数`0`被视为三个十进制数字`000`，表示从文件中执行句子，在出现错误时停止，并且进行静默加载（不显示句子或结果）。
