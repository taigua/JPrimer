# 绘图区域

绘图还说明了使用区域的一种常用技术。关闭J并重新启动它以获得一个干净的环境。
`base`区域中没有动词名字，但是`profile.ijs`脚本加载了一些其他标准区域。
```j
   names 3	NB. verbs
   names 6	NB. locales
base     j        jcompare jgl2     jp       jqtide   jregex   jrx      jtask    z 
```

动词`load`（在`z`区域中定义）将`plot.ijs`脚本加载到`plot`区域中。

```j
   load 'plot'
   plot ? 5 $ 100	
   names 3
   names 6
base  j     jcfg  jplot z
   plot
+----------+
|plot_plot_|
+----------+
```

动词`plot`没有在`base`区域中定义，而是在`z`区域中定义。当它在`base`区域中执行时，
来自`z`区域的定义就像在其定义在`base`区域中一样执行。输入`plot`名字将显示其定义。
关于`plot`定义的有趣之处在于，它执行在`plot`区域中定义的`plot`动词。
`z`区域中的`plot`是一个在所有语言区域中都有效的覆盖，它的作用是在执行`plot`区域中的`plot`动词。

> 注：在较新的J版本中（J9.7以上），`plot.jis`已经被替换为别的脚本，具体看J实现。

这种技术将像`plot`包这样的工具加载到它自己的区域中，然后在`z`区域中定义覆盖动词，
以便用简单名字引用（不需要加区域后缀）调用功能区域中所需的动词。可以将`plot`区域中的定义
视为该工具包的私有实现，而通过在`z`区域中定义而公开的名字是公共或发布的接口。
