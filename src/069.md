# 框架和单元格

到目前为止，名词一直被视为整体。但是，将阵列视为由单元格组成是有用的，
单元格是阵列的一部分（子阵列），当将其放置在框架中时，就构成了整个阵列。
```j
   a =. 2 3 $ 'abcdef'
   a
abc
def
```

阵列`a`可以被认为有`6`个单元格，每个单元格是一个原子。框架的形是`2 3`，
将`6`个单独的单元格组装到阵列`a`中。视觉上（单元格是原子，框架是`2 3`）：
```j
	a       cell 0
	b       cell 1
	...
	f       cell 5
```

阵列`a`也可以被认为有`2`个单元格，其中每个单元格是一个列表。框架的形是`2`，
将单元格组装到阵列`a`中。视觉上（单元格是列表，框架是`2`）：
```j
	abc   cell 0
	def   cell 1
```

最后，可以认为阵列`a`有一个单元格，其中单元格是一个表格。框架的形为空，
将单元格组装到阵列`a`中。视觉上（单元格是表格，框架是空的）：
```j
	abc   cell 0
	def
```

形为`2 3`的表格可以理解为：
- 一个以原子为单元格，形为`2 3`的框架
- 一个以列表（形为`3`）为单元格，形为`2`的框架
- 一个以表格（形为`2 3`）为单元格的空框架

类似地，形为`4 3 2`的阵列可以被认为是：
- 一个以原子为单元格，形为`4 3 2`的框架
- 一个以列表（形为`2`）为单元格，形为`4 3`的框架
- 一个以表格（形为`3 2`）为单元格，形为`4`的框架
- 一个以秩为3的阵列（形为`4 3 2`）为单元格的空框架

框架是阵列形的前缀。它可以是整个形（以整个形作为前缀），在这种情况下，单元格是原子。
它可以为空（空前缀），在这种情况下，以整个阵列作为单一单元格。或者介于两者之间。

单元格的形是去掉框架前缀后阵列的形。单元格形的长度就是单元格的秩。

阵列的单元格是子阵列，当它们组装到相应的框架中时，就创建了整个阵列。
