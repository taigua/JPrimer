# 分叉

由三个动词组成的序列是一个分叉，其运行方式如下：

```j
  (f g h) y	evaluates as	(f y) g (h y)
x (f g h) y	evaluates as	(x f y) g (x h y)
```

分叉的一个简单示例是三个动词的序列`+/ % #`。副词`/`接受它的左参数`+`并返回一个动词，
因此这是一个由三个动词组成的序列。让我们从单子的角度来研究一下分叉的用法。

```j
   (f  g h) y	evaluates as	(f  y) g (h y)
   (+/ % #) y	evaluates as	(+/ y) % (# y)
```

这可以读作：**参数的总和除以参数的个数**。这就是**均值**的定义。

```j
   (+/ % #) 5 9 12
8.66667
   (+/ % #) i.9
4
```

现在可以将`mean`定义为带有`+/ % #`的分叉。

```j
   mean =. +/ % #
   mean i.9
4
```
