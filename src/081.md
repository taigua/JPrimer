# 副词和连词的执行顺序

副词和连词的优先级高于动词。这意味着副词或连词在动词之前执行。
此外，副词或连词的左参数是它前面的整个动词短语。[NuVoc](https://code.jsoftware.com/wiki/NuVoc)的
[Modifiers](https://code.jsoftware.com/wiki/Vocabulary/Modifiers)辅助页面给出了解析和执行的确切规则。

出于实践目的，下面用示例说明这些规则。

```j
   a =. i.2 3
   +/"1 - a
_3 _12
```

与所有J句子一样，上面的句子从右到左执行。在将`+`解析为双子或单子之前，执行优先级更高的连词`"`。连词以`1`作为它的右参数，
以它左边的整个动词短语作为它的左参数。左边的动词短语是副词，它的左参数是`+`。下面使用括号来明确根据规则所确定的执行顺序。

```j
   ((+/)"1) (- a)
```

如前所述，带有常量的简单例子可能需要将作为连词宾语的常量与作为派生动词宾语的常量分开。

```j
   a (+"1) 1 2 3
   a +"1 (1 2 3)
   a +"1 [ 1 2 3
```

最后一个使用原语单子`[ (same)`来返回它的参数。这样比较短，并且避免了括号的使用。
