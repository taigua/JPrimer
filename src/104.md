# J在线文档

花点时间熟悉**JQt IDE**中的**J Help**菜单中提供的文档。
快速浏览所有的资料是值得的，这样你就知道当有东西出现时去哪里查。

-----------------
[Wiki](https://code.jsoftware.com/wiki/Main_Page) - J Wiki是关于J和许多其他阵列语言信息的宝库。

-----------------
[Vocabulary](https://code.jsoftware.com/wiki/NuVoc) - NuVoc是最新的J语言综合词汇表，它在JQt环境中也有F1功能键作为快捷键。

[Constants](https://code.jsoftware.com/wiki/Vocabulary/Constants) - 关于J中各种字符和数值类型的一个很好的参考。

[Control Structures](https://code.jsoftware.com/wiki/Vocabulary/ControlStructures) - 当你必须使用过程编程时。

[Foreigns](https://code.jsoftware.com/wiki/Vocabulary/Foreigns) - 这么多的外部连词要知道。

Release Notes - 正在运行的J版本的特定改进和功能支持。

-----------------
[Standard Library](https://code.jsoftware.com/wiki/Standard_Library/Overview) - 已加载的J标准库。
很多有用的动词已经为你写好了。如果你喜欢重新发明轮子，那就忽略它，但如果你想要一个良好的开端，看看。

[Window Driver](https://code.jsoftware.com/wiki/Guides/Window_Driver) - 在JQt环境中开发界面所需要知道的一切。
如果你对`ijx`和`ijs`窗口很满意，并且是自己的最终用户，那么忽略它。如果你想构建更完整的应用程序，并可能将其提供给其他终端用户，
那么你需要花时间学习这些东西。**Qt Demos**和**Studio**中的**Showcase**部分在掌握JQt环境方面是无价的。

-----------------
Studio
- Labs - 让你获得优秀的J互动学习机会。
- Advance - 推进当前实验的快捷键：*Ctrl-J* （Mac上是*Cmd-J*）。
- Chapters - 较大的实验可以有许多章节，这让你更容易导航。
  - -------------
- Qt Demos - Qt组件的演示，包括每个演示的源代码。
  - -------------
- Showcase - 已经构建的更复杂的Qt接口的交互式示例。

-----------------
Context Sensitive - *Ctrl-F1*（Mac上是*Cmd-F1*）将直接带你到任何高亮显示的词类的NuVoc页面。
