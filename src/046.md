# 调试——处理错误

让我们在你的摄氏度动词中引入一个错误，看看它是什么样子的，以及你如何发现和修复它。

打开你的`cf.ijs`脚本并编辑第一行，通过在连词`=.`右侧的表达式两边添加引号来制造错误。
```j
t1 =. 'y - 32'
```

`t1`不再被定义为`y - 32`的结果，它将被定义为字符串。

运行脚本生成新的定义。关闭调试暂停，并清除断点，然后运行有bug的摄氏度动词。
```
   dbr 0	NB. disable suspension
   dbss ''
   centigrade 212 NB. Error messages in versions prior to J9.4
|domain error
|   t2=.t1    *5

   centigrade 212    NB. Expanded error messages in J9.4
|domain error in centigrade, executing dyad *
|x is character
|   t2=.t1    *5
```

你正在禁用暂停（`dbr 0`）的情况下运行，所以执行没有在摄氏度上暂停，缩进依然是正常的3个空格。

如果你看一下错误行，很明显，`5`是乘法的有效参数，所以`t1`一定有问题。但是你不知道`t1`的值。
你可以查看源代码找错误，但是，在复杂的情况下，使用debug可能会更快。

启用暂停并重新运行。
```j
   dbr 1	NB. enable suspension
   centigrade 212
|domain error
|   t2=.t1    *5
|centigrade[1]
```

此时光标会缩进6个空格表示暂停，因为摄氏度被暂停了，你可以看看`t1`的值。
```j
      t1
y - 32
```

从`t1`的显示可以清楚地看出它是一个字符串，而不是所需计算的数字。现在可以查看源代码，
看看`t1`是在哪里定义的，并发现引号不应该出现在那里。

编辑源代码，通过删除引号来修复定义，并运行脚本来重新定义摄氏度动词。

要重新运行第0行来正确地定义`t1`，你可以通过使用`dbjmp`从第0行继续执行。
```j
      dbjmp 0
100
```

由于没有设置断点，也没有其他错误，因此摄氏度第0行被执行，它将给局部名字`t1`设置正确的值，并继续执行直到完成。
