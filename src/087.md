# 取自（分散索引）

如果左参数是单体，则打开它，并且它的项是沿连续轴的索引。

```j
      (<0 2 ; 2 3) { m
 2  3
10 11
```

如果左参数不是单体的呢？

```j
   (0 2 ; 2 3) { m
2 11
```

这是怎么回事？没什么特别的，因为这只是你的老朋友`" (rank)`。
双子`{`的左秩是`0`，右秩是`_`。这意味着左参数被当作0元格，右参数被整体拿来使用。可视化看:

```j
(<0 2)  (first left cell)  { m   gives 2
(<2 3)  (next left cell)   { m   gives 11
```

结果由部分结果`2`和`11`组合而成。

这被称为分散索引。

```j
   (0 0 ; 1 1 ; 2 2) { m	   NB. scatter index a diagonal
0 5 10
```
