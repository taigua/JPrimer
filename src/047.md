# 比较原语

如果左右参数相等，则双子`=`的结果为1，如果它们不同，则结果为0。
```
   23 = 34
0
   23 = 23
1
   a =. 'd'
   a = 'c'
0
   7 + a = 'c'
7
   7 + a = 'd'
8
```

一些编程语言将比较原语（如`=`）的结果视为非数字的`True`和`False`值。在J中，比较的结果只是数字。

还有其他几个比较动词：小于`<`、小于等于`<:`、大于`>`和大于等于`>:`。这些比较原语有时被称为关系原语。
```
   7 < 8
1
   7 < 7
0
   7 <: 7
1
```
