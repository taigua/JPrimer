# 字符串

用单引号括起来的字符创建一个字符串。
```j
   char =. 'Q'
   chars =. 'this is a list of characters' 
```

显示字符串时不显示单引号。
```j
   char
Q
   chars
this is a list of characters
```

单引号用于字符串的开始和结束。一对单引号表示引号字符本身在字符串中。
```j
   'put 2 ''s to get 1 '' in the string'
put 2 's to get 1 ' in the string
```

不匹配的单引号是错误的。
```j
   abc =. 'asdf
|open quote
```

字符串可以为空。
```j
   abc =. ''
```

字符串也被称为字面值常量或字符常量。
