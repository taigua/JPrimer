# 名字

原语是由系统定义的单词，而名称是由你定义的单词。原语`=.`定义一个名字。
```j
   5 + v
28
```

这个句子可以读作`v`是`23`。单词`=.`叫做**系动词**（另一个很好的英语术语）。名字`v`被定义为数字`23`，可以用在其他句子中。

与原语不同，名字可以重新定义。
```j
   v =. 45
   5 + v
50
```

当句子以系动词开始时，系统不会显示句子的结果。只包含名字的句子将显示名字所定义内容的显示形式。
```j
   abc =. 123
   abc
123
```

你可以给任何东西起名字。例如，你可以给动词`+`起一个名字。
```j
   plus =. +
   23 plus 45
68
```

`abc =. def`的一般读作：`abc`被定义为`def`。然而，借用其他计算机语言，也常说：`abc`被赋值为`def`或将值`def`赋给abc。
