# 控制结构

在摄氏度中，定义中的句子只是一个接一个地按顺序执行。要有条件地控制执行哪些句子，可以使用控制结构。

控制结构由控制词和句子组成。下面是一个控制结构的例子：
```j
if. x = 'c'
 do. centigrade y
 else. fahrenheit y
end.
```

控制词`if.`开启控制结构，控制词`end.`结束控制结构。`x = 'c'`句子的值是测试结果，
它决定了控制结构中哪个句子被执行。如果测试结果为`1`，则控制词`do.`后的句子被执行。
如果测试结果是**任何其他值**，则控制词`else.`后面的句子被执行。
用汉语解释就是：如果左参数`x`等于字母`c`，则执行摄氏温度，否则执行华氏温度。

使用此功能可以在`cf.ijs`脚本中添加一个新的动词，该动词将根据左参数的值将数字
从华氏度转换为摄氏度，或从摄氏度转换为华氏度。打开`cf.ijs`脚本，并在最后添加以下定义。
```j
NB. convert f to c if x is 'c', otherwise c to f
convert =: dyad : 0
if. x = 'c'
 do. centigrade y
 else. fahrenheit y
end.
)
```

以上定义了动词的二元形式。这个双子有一个左参数`x`，一个右参数`y`。动词的左参数为`'c'`时，
将华氏度转换为摄氏度。除了`'c'`以外的任何左边参数都会将摄氏度转换为华氏度。

注意，动词华氏度和摄氏度的用法就像使用原语动词一样。

运行脚本并测试转换。
```j
   'c' convert  212
100
   'f' convert 100
212
```

通常一个句子是脚本中的一行。但是，使用控制词将一行分隔成几个句子，就有可能在一行中包含多个句子。

下面的单行相当于前面使用的多行。
```j
if. x = 'c' do. centigrade y else. fahrenheit y end.
```

控制结构只允许在脚本中使用，不能直接在REPL窗口中输入执行控制结构。

有九种控制结构模式：
```j
if. T do. B end.
if. T do. B else. B1 end.
if. T do. B elseif. T1 do. B1 elseif. T2 do. B2 end.
try. B catch. B1 end.
while. T do. B end.
whilst. T do. B end.
for. T do. B end.
for_i. T do. B end.
select. T
 case. T0 do. B0
 case. T1 do. B1
 fcase.T2 do. B2
 case. T3 do. B3
end.
```

控制结构以`if.`、`try.`、`while.`、`whilst.`、`for.`、 `for_i.`或`select.`开始，并以一个匹配的`end.`结束。

以**T**或**B**开头的单词表示由0个或多个句子组成的块，并且可以包含嵌套的控制结构。

T块中最后一个句子的结果决定接下来执行哪个块，以及控制结构是否执行完毕。

通常，T块是一个简单的句子，可以做一个简单的测试，就像上面例子中的一样。

`try.`控制结构是一个有趣的结构。它执行B块句子，如果没有错误，它就跳到结构的末尾。但是，如果出现错误，则执行B1块。

`while.`控制结构执行T块，如果其结果不为0，则执行B块并继续执行，直到T块的结果为0。如果T块第一次为0，则B块不执行。

`whilst.`控制结构与`while.`相同，除了T块第一次被跳过。这意味着B块总是至少执行一次。

在`for.`控制结构中，B块对数组A中的每一项求值一次，该数组A是由求值T块产生的。在`for_i.`形式中，
局部名字`i`被设置为每次对B块求值时项的值，`i_index`被设置为该项的索引。控制词`break.`跳到`for.`控制结构的结尾，
控制词`continue.`跳到B块对下一项的进行求值。

在`select.`控制结构中，T的结果**R**与Ti的结果Ri进行比较，第一个匹配的`case.`或`fcase.`中的Bi将被执行。
如果匹配的是`case.`，则`select.`控制结构的执行就此结束；如果匹配的是`fcase.`，则下一个`case.`或`fcase.`
的B(i+1)块将被执行。如果下一个是`fcase.`，则还会继续执行下下一个，直到遇不到`fcase.`或执行到`select.`的结尾。

有关控制结构的更多信息，请参考[NuVoc](https://code.jsoftware.com/wiki/Vocabulary/ControlStructures)。
