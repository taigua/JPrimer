# 数据处理

应用程序通常具有GUI部分和数据处理（DP）部分。DP部分是实际的计算和数据操作。
一个好的应用程序实现是模块化的，这意味着GUI和DP部分之间有明确的区别。

在本节中，你将开发一个简单应用程序的DP部分。在下一节中，你将开发GUI部分。

应用程序的DP部分规范如下：

```
The input is the name of a text file. The output is a string that displays as a table that contains: 
the file name, a count of lines, a count of characters, and a row for each distinct character in the 
file and a count of how many times it appears in the file. The rows of distinct characters should be 
sorted by their counts.
```

你将和文件打交道，因此请加载文件实用程序。

```j
   load 'files'
```

创建一个简单的文本文件用作测试数据。

```j
   fn =. jpath '~user/text.txt' NB. ~user/ is required for path to place file in user folder
   data =. 'abc' , LF, 'bc' , LF, 'b' , LF
   data fwrite fn
9
   fread fn
abc
bc
b
```

你需要定义一个动词`report`，它以文件名作为参数并返回指定的结果。
你将在**Term**窗口中构建定义的各个部分，然后将它们一起放入脚本中的定义中。

输入是一个文件名，在动词`report`中，它的名称为`y`，因此首先在**Term**窗口中处理`y`。

```j
   y =. jpath '~user/text.txt'
```

读取文件。

```j
   d =. fread y
```

报告将有两列。第一列将是标签`'File:', 'Lines:', 'Chars:'`以及文件中的每个不同字符。
第二列将是该行的值。由于数据是文本和数字的混合，因此将结果构建为盒装数据是有意义的。

用固定的标签创建一个名词。

```j
   r =. 'File:' ; 'Lines:' ; 'Chars:'
   r
+-----+------+------+
|File:|Lines:|Chars:|
+-----+------+------+
```

这些标签值的计算方法如下：

```j
   y ; (+/ LF = d) ; #d
+-------------+-+-+
|user\text.txt|3|9|
+-------------+-+-+
```

双子`,. (stitch)`可以把这两个列表连接成一张表格。

```j
   r =. r ,.  y ; (+/ LF = d) ; #d
   r
+------+-------------+
|File: |user\text.txt|
+------+-------------+
|Lines:|3            |
+------+-------------+
|Chars:|9            |
+------+-------------+
```

下一件事是添加包含字符及其频率计数的行。字母是标签，计数是值，
所以它只是向`r`中添加了更多的项。让我们推迟处理这部分问题，
转而将盒装表格转换为规范要求的字符串结果。使用注释来标记我们现在跳过的部分。

```j
   NB. need to add frequency rows to r here
```

第二列中的数字需要转换为字符。最简单的方法是将每个盒子的内容转换为字符。
字符已经是字符，不受影响，但任何数字都将被转换。

```j
   r  =. ":each r
   r
+------+-------------+
|File: |user\text.txt|
+------+-------------+
|Lines:|3            |
+------+-------------+
|Chars:|9            |
+------+-------------+
```

`r`的所有字符显示看起来是一样的，但是每个盒子现在包含的是字符。

下一步很有趣，细节留给你去琢磨。它在每个标签后面添加一个`TAB`，在每个值后面添加一个`LF`。
在最后的结果中，`TAB`将标签与其值分开，`LF`为下一个标签生成新的行。盒装显示显示`TAB`和`LF`为空白，但它们确实在那里。

```j
   r =. r ,each"1 1 TAB;LF
   r
+-------+--------------+
|File:  |user\text.txt |
+-------+--------------+
|Lines: |3             |
+-------+--------------+
|Chars: |9             |
+-------+--------------+
```

单子`; (raze)`打开所有的盒子并组装一个字符串结果。

```j
   ; r
File: 	user\text.txt
Lines:	3
Chars:	9
```

现在可以定义动词`report`了。创建一个新脚本并将其保存为`jpath '~user\textdp.ijs'`。
将其和**Term**实验放在一起，将以下`report`定义添加到脚本中。

```j
report =: 3 : 0
d =. fread jpath y
r =. 'File:' ; 'Lines:' ; 'Chars:'
r =. r ,. y ; (+/ LF = d) ; #d
NB. need to add frequency rows to r here
r =. ":each r
r =. r ,each"1 1 TAB;LF
; r
)
```

运行脚本测试`report`。

```j
   report fn
File: 	user\text.txt
Lines:	3
Chars:	9
```

现在计算频率行。你需要一个动词`freq`，它返回一个盒子表格，其中第一列是不同的字符，
第二列是它们在文件中出现的次数。`freq`的参数是文件数据，在`freq`内部，它的名称是`y`，
所以让我们从定义为文件数据的`y`开始。

```j
   y =. fread fn
```

数据可能包括`TAB`、`CR`和`LF`字符，它们应该被删除。双子`-. (less)`可以删除这些不需要的字符。

```j
   d =. y -. TAB,CR,LF
   d
abcbcb
```

`nubcount`，定义为`nubcount=: ~.;"_1 #/.~`，返回一个盒子表格，其中第一列包含参数中的不同项，第二列包含计数。

```j
   nubcount=: ~. ;"_1 #/.~
   nc =. nubcount d
   nc
+-+-+
|a|1|
+-+-+
|b|3|
+-+-+
|c|2|
+-+-+
```

要按计数对项进行排序，你需要将计数放入列表中。

```j
   > 1 {"1 nc
1 3 2
```

双子`\: (sort down)`根据其右参数对其左参数的项进行排序。

```j
   nc \: > 1 {"1 nc
+-+-+
|b|3|
+-+-+
|c|2|
+-+-+
|a|1|
+-+-+
```

将所有这些放在一起，并将以下定义添加到脚本中。

```j
freq =: 3 : 0
d =. y -. TAB,CR,LF
nc =. nubcount d
nc \: > 1 {"1 nc
)
nubcount=: ~. ;"_1 #/.~
```

运行脚本测试`freq`。

现在可以在动词`report`中使用`freq`。修改`report`种的`NB.`注释行为：

```j
r =. r , freq d
```

运行脚本测试`report`。
```j
   report fn
File:	user\text.txt
Lines:	3
Chars:	9
b	3
c	2
a	1
```

在其他文本文件上尝试一下。

你已经完成了数据处理部分。
