# 优先级

数学传统上认为乘法优先于加法。在数学课上，如果有人问你`2 + 3 * 4`等于多少，你要知道答案是`14`。

如果只有几个函数和几个级别的优先级(除法|乘法|加法和减法)，这并不太令人困惑。但事情在诸如C这样的语言中会变得笨拙，
因为有许多功能和优先级级别。

由于J中有大量的动词，很难定义优先级，更不用说在阅读或编写时试图记住它了。
此外，能够命名事物意味着你还必须弄清楚如何处理这个句子：
```j
   2 plus 3 times 4
```

与传统数学以及大多数其他编程语言不同，J没有动词优先级。你可能需要一点时间先停止乘法，但整体的简化是值得的。

记住：**没有**动词优先级。
