# 调试——逐步执行

在前面的一节中，你向动词定义添加了调试行，使你能够在运行动词时查看中间步骤的结果。
有时候你需要更强大的工具。

在J的最新版本中包含了调试工具，但如果没有，你可以用`load 'debug'`来加载调试工具。

打开脚本文件`cf.ijs`并运行它。

让我们执行摄氏度，但是每一行都有一个停顿，以便你可以确切地看到正在发生什么。
```j
   dbss 'centigrade *:*'
```

`dbss (Set Stop)`的参数声明在执行所有摄氏度的行（用`*:*`表示）之前有一个断点。
```j
   dbr 1
```

参数为`1`的`dbr`要求系统在发生错误或断点时暂停执行。当动词被暂停时，它在执行过程中停止。
你可以检查定义、更改定义，还可以恢复暂停动词的执行。
```j
   centigrade 212
|stop
|       t1=.y-32
|centigrade[0]
```

错误报告（在左侧行首的竖线）指出执行在摄氏度时在第0行暂停，并显示该行中的句子。

摄氏度的执行被暂停，缩进六个空格，而不是三个，表示暂停。变量`y`是参数。
```j
      y
212
```

暂停发生在行执行之前，所以`t1`没有被定义，如果你试图查看它，你将得到一个值错误。

使用`dbrun`继续执行。它将执行当前行，因为所有行都设置了断点，所以它将在下一行暂停。
```j
      dbrun ''
|stop
|       t2=.t1*5
|centigrade[1]
      t1
180
      t1*5
900
```

现在，摄氏度在第一行暂停了，正如你所看到的，你可以检查在第0行中定义的局部`t1`的值。继续调试后续的行，检查局部名字。
```j
      dbrun ''
|stop
|       t3=.t2%9
|centigrade[2]
      t2
900
      t2%9
100
      dbrun ''
100
```

摄氏度执行完毕后，你又回到了正常的三个空间的缩进。

关闭调试暂停请求并重置为没有断点。
```j
   dbr 0
   dbss ''
```
